# Prompts para asistentes de IA

Instrucciones listas para copiar en cualquier asistente (Claude, ChatGPT, Copilot Chat, Cursor…) que trabaje sobre este repositorio. Todas parten de `AGENTS.md`, así que el asistente debe poder leer el repositorio.

| Archivo | Cuándo |
| --- | --- |
| `nueva-funcionalidad.md` | Añadir algo nuevo al juego |
| `corregir-error.md` | Arreglar un fallo |
| `cambio-visual.md` | Cambiar diseño, animaciones o textos |
| `revision-de-codigo.md` | Revisar un pull request |

Rellena lo que va entre `<…>` antes de enviarlo.
